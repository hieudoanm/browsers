# browsers-layout

Experimental layout component of the browserverless pure-Rust engine
prototype.

Block layout: `LayoutBox`, `BoxType`, `Rect`, `LayoutContext`, `build_layout_tree`, `layout` — turns DOM + computed styles into positioned boxes.

## Status

**Not a workspace member** — this crate is preserved for the engine
experimentation from an earlier prototype phase and is intentionally excluded from
`cargo build --workspace`. Several of its dependencies are not yet wired into
the workspace manifest.
